Frequently asked

Do I need an account?
No. Dayspan has no server. Install it and start.
Where is my data?
Only on your phone. See the privacy policy.
Does Dayspan change my calendar?
Never. It has read-only access and shows today's events next to your tasks and habits. Events are read fresh each time and are not stored.
My calendar events don't show up.
Open Settings → Connect calendar in the app. If you declined the permission earlier, enable it under iOS Settings → Dayspan → Calendars.
Reminders or the morning brief don't arrive.
Check that notifications are allowed under iOS Settings → Dayspan → Notifications. Reminders are set per task or habit in its editor; the morning brief is off by default and lives in the app's Settings.
What does "Alarm" on a reminder do?
On iOS 26 and later, it rings like a real alarm even in silent mode or a Focus. On older iOS versions the option is not shown.
What do the tile dots and the history map mean?
The seven dots on a tile are this week, Monday to Sunday. Tap a tile to open its page: the history map shows the last six months, one square per day, lit in the habit's colour when you completed it.
If I switch phones, does my data move with me?
Not yet. Data is kept on the device only in this version.
How do I delete my data?
In the app: Settings → Start over. Or delete the app.

Reporting a bug

Dayspan is open source. Report bugs and ideas through GitHub Issues or by email.

Open source and licence

All of Dayspan's source code is public on GitHub under the MIT licence. You can read it, change it and use it in your own projects.
